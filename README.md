# Polymarket PnL Exporter

A simple, client-side tool to analyze and export the daily net value history of a Polymarket account. It fetches real-time data, calculates historical performance, and exports everything to CSV for further analysis.

![App Screenshot](https://github.com/user-attachments/assets/22c5091d-ec0e-4772-99be-bf919ab88ae2)

## 🚀 Features

- **User Resolution:** Supports both Ethereum addresses (`0x...`) and Polymarket usernames (`@Username`).
- **Real-Time Data:** Fetches live Cash Balance (USDC on Polygon) and current Position Value.
- **Dual Calculation Methods:**
  - **Net Value (from Current):** Backward-calculated based on your current total account value (zero configuration required).
  - **Net Value (Forward):** Forward-calculated starting from a custom "Opening Balance" you provide.
- **Privacy Focused:** Runs entirely in the browser. No server-side storage.
- **Visualization:** Interactive chart using Chart.js.
- **Export:** One-click CSV export containing Date, Profit/Loss, and calculated Net Values.

## 📖 Usage

1. **Open the Tool:** Simply open `index.html` in any modern web browser.
2. **Enter User:** Type your Polymarket username (e.g., `@Username`) or wallet address.
3. **Set Opening Balance (Optional):** If you know your initial deposit amount, enter it to get an accurate forward-calculated Net Value curve.
4. **Load Data:** Click **"Load Data"**. The tool will fetch PnL history, resolve the address, and query the Polygon blockchain for USDC balances.
5. **Export:** Once data is loaded, click **"Export CSV"** to download the dataset.

## 🔗 APIs Used

- **Polymarket PnL:** `user-pnl-api.polymarket.com`
- **Polymarket Data:** `data-api.polymarket.com`
- **Profile Search:** `polywallet.info`
- **Blockchain Data:** `polygon-rpc.com` (for USDC balance)
- **CORS Proxy:** `api.allorigins.win` (to enable client-side fetching)

## 📦 Dependencies

- **Tailwind CSS** (Styling)
- **Chart.js** (Graphing)
